# 东宋帝国

这是一个架空历史世界观小说。其名称和最初创意来自 B 站 [@鱼干悠暖的埋骨地](https://space.bilibili.com/zh-Hans/22042016) 的 [东宋联省共和国](https://space.bilibili.com/zh-Hans/22042016/lists/23849?type=season) 作品系列。但需要声明的是，本作在内容上与该作没有必然联系，也算不上二次创作。

**东宋帝国** ，正式名称为 **大宋** ，是一个虚构的联邦制君主 / 君主立宪国家。1273 年，南宋在 [襄樊之战](https://zh.wikipedia.org/wiki/%E8%A5%84%E6%A8%8A%E4%B9%8B%E6%88%98) 中战败，遂采取流亡海外的国策。1275 年，**宋世祖 赵昺** 在前往吕宋的航行中加冕为皇帝，建立东宋帝国。
